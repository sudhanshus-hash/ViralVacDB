# ViralVacDB: Viral Vaccine Database

Welcome to the official repository and documentation overview for **ViralVacDB**, a manually curated repository of viral vaccines. This platform provides comprehensive and structured information on vaccines developed against various viral diseases, supporting researchers, clinicians, and immunoinformatics experts.

**Web Server:** [https://webs.iiitd.edu.in/raghava/viralvacdb/](https://webs.iiitd.edu.in/raghava/viralvacdb/)

## About the Database

ViralVacDB is a comprehensive and user-friendly resource developed to address the lack of centralized information on viral vaccines. It integrates scattered data from literature, clinical trial repositories, and regulatory agencies into a single platform.

The database provides detailed information on:

* Vaccine types
* Routes of administration
* Clinical status and approval
* Associated viral diseases
* Dosage, age group, and target strains

It currently contains data for **422 viral vaccines**, including:

* **145 approved vaccines**
* **277 vaccines in clinical trials** 


## Key Features

### Comprehensive Dataset

* Coverage of vaccines against **26 human viral diseases**
* Includes both **approved and experimental vaccines**
* Categorization based on vaccine type (whole pathogen, subunit, nucleic acid, viral vector)

### Rich Annotations

Each vaccine entry contains:

* Vaccine name and type
* Disease targeted
* Route of administration (intramuscular, oral, intranasal, etc.)
* Manufacturer and country
* Clinical phase and approval status
* Dosage and age group

### Built-in Tools

* **Search Module:** Basic and advanced search with filters
* **Browse Module:** Explore data by disease, vaccine type, or administration route
* **Download Suvidha :** Export results in structured formats


## Overview

The ViralVacDB system is built on a **LAMP architecture**:

* **Backend:** MySQL database
* **Server:** Apache
* **Frontend:** HTML, CSS, JavaScript, PHP

### Core Modules:

1. **Search Module** – Query vaccines using multiple parameters
2. **Browse Module** – Navigate datasets easily
3. **Viral Diseases Module** – Detailed disease-level information
4. **External Links** – Integration with DrugBank, NCBI, PubChem
5. **General Information** – Statistics and help documentation


## Applications

* **Vaccine Research:** Identification and comparison of vaccine candidates
* **Immunoinformatics:** Data-driven analysis of vaccine design
* **Clinical Insights:** Understanding vaccine approval and trial status
* **Public Health:** Studying vaccine distribution across diseases



## Data Collection

Data in ViralVacDB is manually curated from:

* Regulatory bodies (FDA, WHO, CDC, CDSCO)
* ClinicalTrials.gov
* Published scientific literature 


## Utility

ViralVacDB enables users to:

* Perform targeted vaccine searches
* Analyze vaccine distribution by disease or type
* Access complete vaccine profiles through unique IDs
* Retrieve structured and downloadable datasets
